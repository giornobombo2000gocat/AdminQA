# Исходники админки для локального QA-демо

Это отдельная исходная версия существующей админки. Она работает только с localhost / 127.0.0.1 / ::1; внешние запросы браузерной сессии блокируются. Вход и игра на реальных сайтах не реализованы в этой поставке. Это не универсальный адаптер сайтов.

## Запуск на Windows

1. Установите Python 3.12 и распакуйте весь архив.
2. Запустите SETUP.cmd. Установка библиотек и Chromium требует интернета.
3. Запустите START.cmd.
4. Нажмите «Проверить на демо» в админке. Порт 5000 должен быть свободен.

Включены интерфейс PySide6, управление независимыми сессиями, хранение настроек, журналирование, Playwright/CDP, API FastAPI, локальное демо и ScopaEngine.exe с исходниками engine/ и backend/. Демонстрационные логин и пароль в workflow_demo.py относятся только к встроенному тестовому сайту.

Настройки и логи создаются в QA_data рядом с программой. Сохранённые настройки пользователя, реальные пароли, прокси и профили браузеров не включены.

BUILD.cmd собирает dist/QA_Manager.exe. Текущая админка запускает ShardBrowser и подключается через Playwright/CDP. Shard runtime не включён в архив: при первом запуске он загружается отдельно; нужен интернет. Можно использовать существующую папку shard-runtime рядом с исходниками. Дополнительная папка vision-runtime с моделями Ollama также не включена. Для локального демо модель не требуется.

Основные файлы: desktop_app.py — интерфейс; test_orchestrator.py — циклы сессий; room_agent.py — агент локального демо; scopa_qa.py — полный JSON и проверка хода; engine_server.py — API; desktop_store.py — настройки. Матдвижок предназначен для Scopa; логика других игр отсутствует.

Архив проверяется на синтаксис, комплектность локальных импортов и ограничение URL. Предыдущие тесты EXE относятся к прежней сборке, а не к этой отдельной поставке исходников.
