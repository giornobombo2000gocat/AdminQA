# Исходники админки для локального QA-демо

Это отдельная исходная версия существующей админки. Она работает только с localhost / 127.0.0.1 / ::1; внешние запросы браузерной сессии блокируются. Вход и игра на реальных сайтах не реализованы в этой поставке. Это не универсальный адаптер сайтов.

## Запуск на Windows

1. Установите Python 3.12 и распакуйте весь архив.
2. Запустите SETUP.cmd. Установка библиотек и Chromium требует интернета.
3. Запустите START.cmd.
4. Нажмите «Проверить на демо» в админке. Порт 5000 должен быть свободен.

## Stagehand и промпты

Установите Google Chrome или Microsoft Edge и запустите локальный Ollama. После обновления выполните SETUP.cmd, затем START.cmd. Нажмите **Stagehand • промпты для ИИ**. В новом окне укажите имя установленной модели, нажмите **Открыть браузер агента**, затем **Выполнить промпт**.

Пример: «Открой карточные игры, выбери Scopa, открой учебную комнату и стол 5». Это отдельный браузер агента и собственный локальный QA-сервер со случайным свободным портом; порт 5000 ему не нужен. Основной цикл математического движка не меняется. Агент не управляет активными браузерными сессиями основной панели и не передаёт им команды.

Поле постоянных инструкций сохраняется между запусками. Это память инструкций, а не дообучение весов модели. Каждая задача ограничена 8 шагами и 4 минутами; кнопка **Отмена** прерывает текущую задачу, не отменяя уже выполненные клики. Поддерживается текстовый DOM; скриншоты в модель не передаются. Внешние домены блокируются на уровне браузера. Закрытие окна агента завершает принадлежащий ему браузер и локальный сервер.

Модель по умолчанию: `hf.co/mradermacher/Qwen3-4B-abliterated-GGUF:Qwen3-4B-abliterated.Q4_K_M.gguf`. Это установленная на рабочей машине версия Qwen3 4B Abliterated в Q4_K_M, около 2,5 ГБ весов. Автор позиционирует её как модель со сниженными отказами; отсутствие отказов и правильность действий не гарантируются. Весы не включены в репозиторий. Если её нет в Ollama, выберите свою локальную модель или установите выбранную самостоятельно. Документация модели: https://huggingface.co/mradermacher/Qwen3-4B-abliterated-GGUF .

Интеграция использует официальный Python SDK `stagehand==4.1.0` и локальный Ollama callback, без облачных API-ключей. Документация: https://docs.stagehand.dev/v4/configuration/models .

Включены интерфейс PySide6, управление независимыми сессиями, хранение настроек, журналирование, Playwright/CDP, API FastAPI, локальное демо и ScopaEngine.exe с исходниками engine/ и backend/. Демонстрационные логин и пароль в workflow_demo.py относятся только к встроенному тестовому сайту.

Настройки и логи создаются в QA_data рядом с программой. Сохранённые настройки пользователя, реальные пароли, прокси и профили браузеров не включены.

BUILD.cmd собирает dist/QA_Manager.exe. Текущая админка запускает ShardBrowser и подключается через Playwright/CDP. Shard runtime не включён в архив: при первом запуске он загружается отдельно; нужен интернет. Можно использовать существующую папку shard-runtime рядом с исходниками. Дополнительная папка vision-runtime с моделями Ollama также не включена. Для локального демо модель не требуется.

Основные файлы: desktop_app.py — интерфейс; test_orchestrator.py — циклы сессий; room_agent.py — агент локального демо; scopa_qa.py — полный JSON и проверка хода; engine_server.py — API; desktop_store.py — настройки. Матдвижок предназначен для Scopa; логика других игр отсутствует.

Проверены синтаксис исходников, вызов реальной локальной модели, клики через Stagehand, переход до учебного стола и закрытие принадлежащих агенту ресурсов. Для проверки собранного EXE: `QA_Manager.exe --stagehand-self-test report.json`. Нужны установленная модель по умолчанию, запущенный Ollama и Chrome/Edge. Тест открывает отдельный браузер без окна и создаёт JSON-отчёт, не меняя сохранённые пользовательские настройки.
